# 🔐 SecureAuth - Full Stack Authentication System

A modern authentication system built with HTML, JavaScript, Tailwind CSS, JWT-based session management, and Two-Factor Authentication (2FA). This project demonstrates secure user authentication workflows with a clean and responsive user interface.

## 🚀 Features

- User Registration & Login
- Password Hashing (SHA-256 Simulation)
- JWT Access & Refresh Tokens
- Two-Factor Authentication (2FA)
- QR Code Based Authenticator Setup
- Password Strength Meter
- Remember Me Functionality
- Session Management
- Auto Token Refresh
- Dark Mode Support
- Responsive UI Design
- Toast Notifications
- User Dashboard

## 🛠️ Technologies Used

- HTML5
- JavaScript (ES6+)
- Tailwind CSS
- QRCode.js
- OTPAuth.js
- Font Awesome
- Web Crypto API
